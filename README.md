## About Me

I am a **B.Tech Computer Science undergraduate at SRMIST** with a **9.46 CGPA**, building end-to-end products across web, mobile, applied AI/ML, and security-aware systems.

I enjoy taking an idea from a rough problem statement to working interfaces, APIs, data pipelines, integrations, and demos. My work currently spans full-stack product engineering, multimodal AI research, cybersecurity, and hackathon development.

- **Web Development Intern — IndianOil (IOCL):** built a real-time news monitoring dashboard with a Node.js/Express backend, live API integration, caching, fallbacks, search, filtering, and bookmarks.
- **Cybersecurity Intern — Supraja Technologies:** worked with web application VAPT concepts and tools including Nmap, WHOIS, and DVWA.
- **Undergraduate Research:** evaluating Vision-Language Models for anticipatory reasoning on Indian roads using dashcam and OpenStreetMap context.
- **Based in:** Chennai, India.
